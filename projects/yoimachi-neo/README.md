# 宵町ネオ（よいまち・ねお）公式サイト

架空のVTuber「宵町ネオ」の紹介ページ。世界観・キャラクター設定からデザイン・実装までを一貫して制作したプロジェクト。

- 公開パス: `/projects/yoimachi-neo/`
- 構成: `index.html` + `assets/css/style.css` + `assets/js/script.js`（Vanilla / ライブラリ不使用）
- キャラクタービジュアル: インラインSVG（ネオン管の線画）。画像素材に頼らず、ネオンサイン自体をキャラクター表現にしている

---

## 1. コンセプト

> **「今夜も、営業中。」**

昭和49年から大阪・阿倍野の路地で灯り続けた純喫茶「ルナ」の袖看板。
2024年の閉店とともに取り外されたそのネオン管に宿っていた付喪神が、
役目を終えた灯りたちの集まる電脳の街「残光街（ざんこうがい）」で目を覚まし、
"電脳支店"として深夜の喫茶を開いた——という設定のVTuber。

ターゲットは「夜更かしの人」。配信は夜型で、視聴者を"常連さん"として迎える。
レトロ（昭和喫茶・ネオン・ブラウン管）× 電脳 の組み合わせで、ノスタルジーと少しの寂しさ、
それを笑いに変える関西の軽さを同居させる。

## 2. 世界観：残光街（ざんこうがい）

- 役目を終えた「灯り」たちが流れ着く、ネットワークの片隅にある街
- 住人は、撤去された看板、消された街灯、捨てられたブラウン管、電球の切れた自販機など
- 街が開くのは **毎晩 0:00〜5:00 だけ**。夜明けとともにシャッターが降りる
- 灯りは「誰かに見てもらうこと」で光量を保つ。見る人がいなくなると、少しずつ暗くなる
  → だから配信をする。視聴者の"視線"が、彼女の電力

### 性格
- 52年間ずっと路地を見下ろしていたので、人間観察が趣味で、話し上手より聞き上手
- 半世紀分の常連の噂話を覚えている（固有名詞はぼかす）
- 自分が「古い」ことを気にしているが、それを自虐ネタにできる強さがある
- 根は寂しがり。配信の終わり際はいつも少し名残惜しそう

### ビジュアル（立ち絵の指定）
- **髪**: ネオン管のように発光する二色のボブ。ピンク → シアンのグラデーション。右の毛先だけ接触不良で点滅する
- **目**: 左目はウィンク。瞳はアンバー（看板の地の色）
- **ヘアピン**: 「営業中」の札型。配信外は「準備中」に裏返る
- **衣装**: 純喫茶のウェイトレス服。白襟＋リボンタイ、フリルのエプロン
- **小物**: クリームソーダ（グラスの縁にさくらんぼ）
- **しっぽ**: 背中から伸びる電源コード。先端はプラグ
- 本サイトでは、立ち絵そのものを「ネオン管で描いた看板」として表現している

## 6. サイト構成

1. **Hero** — ネオンサインのタイトルと、ネオン線画の立ち絵。現在時刻（JST）で「営業中 / 準備中」の札が切り替わる
2. **Story** — 残光街と、看板が目覚めるまでの物語
3. **Profile** — Bento Grid のプロフィール
4. **Design** — 立ち絵のパーツ解説とカラーパレット（クリックでHEXコピー）
5. **Menu** — 喫茶のメニュー表に見立てた配信スケジュール
6. **History** — 点灯の記録（年表）
7. **Footer** — 「本日の営業は終了しました」

### インタラクション
- タイトル文字をクリック／タップすると、その文字だけ接触不良を起こす
- 右上の「ブレーカー」スイッチでネオンを消灯できる（演出を止めたい人向け）
- `prefers-reduced-motion` 有効時は点滅・アニメーションを停止
